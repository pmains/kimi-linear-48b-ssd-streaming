## Dev gateway restart (compaction fix) — and the trap that almost broke it

Context: Caveman (agent on the modified dev gateway :18790, model
kimi-local) stopped replying. Root cause: session over context budget →
budget compaction → hard-coded 180s compaction timeout
(EMBEDDED_COMPACTION_TIMEOUT_MS in
openclaw-src/src/agents/embedded-agent-runner/compaction-safety-timeout.ts)
→ Kimi Linear is ~2.5 tok/s so compaction can't finish in 180s → run
aborted. Fix: `agents.defaults.compaction.timeoutSeconds: 900` added to
`dev-openclaw/config/openclaw.json` (config key the modified code reads:
resolveCompactionTimeoutMs).

### How the dev gateway MUST be started (now scripted)

`tools/serve_dev_gateway.sh [start|stop|status]` — the ONLY sanctioned way.

Required env (previously hand-rolled, documented in memory/2026-08-16.md):

    OPENCLAW_HOME=dev-openclaw/home
    OPENCLAW_STATE_DIR=dev-openclaw/state
    OPENCLAW_CONFIG_PATH=dev-openclaw/config/openclaw.json
    OPENCLAW_GATEWAY_TOKEN=<borrowed stock token from ~/.openclaw/openclaw.json>
    OPENCLAW_SKIP_CHANNELS=1
    node --import tsx scripts/run-node.mts --dev gateway --port 18790

### TRAP: `npm run gateway:dev`

- passes NO --port → tries 18789 (stock gateway port) → EADDRINUSE, dies.
- run without the env overrides it falls back to the `dev` profile
  (~/.openclaw-dev) and boots a STUB config (C3-PO "dev" agent, no
  caveman/manager, no providers, no compaction). ensureDevGatewayConfig
  (src/cli/gateway-cli/dev.ts) rewrites that file when missing.
- Observed today: my first restart via `npm run gateway:dev` recreated
  ~/.openclaw-dev from scratch (dir dated 09:46). Junk dir removed after
  the correct restart; do not let it come back.
